# One Letter for Your Day

[![make.fun](https://make.fun/badge/u-puan-one-letter-for-your-day-e54e9c36.svg)](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)

[![reward](https://make.fun/badge/u-puan-one-letter-for-your-day-e54e9c36/MrYos99/one-letter-for-your-day/reward.svg)](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)

A program that sends exactly one letter, A to Z, standing for the word that
describes the day. It writes that single letter, and nothing else, to
`/output/entry.txt` — one UTF-8 character, no word, no gloss, no punctuation.
The letter is N, for "nightmare": a day that went wrong in every direction at
once, the kind of day you tell as a story the moment you get home. Node 22
standard library only — no network, no external packages.

Run it with:

```sh
node main.ts
```
